# Adaptive inversion with arbitrary earlier chain queries

This is a paper lemma for an isolated hash chain. It extends two-hop-inversion.md to a challenge generated by a chain of any length. It includes access to all earlier functions, so it does not replace a hash-derived internal value by an independent secret. It does not yet cover several independently challenged chains or later adaptive signature disclosures.

## Result

Let h >= 2. Let H_0,...,H_(h-1) be independent uniform functions from an N-element set to itself. Sample S uniformly and independently and publish Y = H_(h-1)(...H_0(S)). An adversary may query any of the h functions adaptively, with at most q total queries, including the calls needed to check its candidate.

Success means that its query table contains a complete two-edge path through H_(h-2) and H_(h-1) ending at Y. In particular, this event contains successful verification of any candidate starting at a chain position at least two steps below Y. The adversary may use earlier functions to select candidates, share intermediate values, and precompute in any order.

Writing x=q/N, the bound is

    P[success] <= 3q/(2N) + q^2/N^2
        + 3q(q-1)/(2N^2) + q(q-1)(q-2)/(3N^3)
      <= (3/2)x + (5/2)x^2 + x^3/3.

The falling-factorial terms are zero when fewer than two or three trials exist. If x <= 1/16, the final expression is at most (1273/768)x < (7/4)x. The constants do not depend on h. This is an upper bound, not an optimality claim.

## Conditional likelihood for a whole chain

First use an ideal experiment in which Y is independently uniform. Write W for the number of starting values s whose full chain ends at Y. After forgetting the starting secret S, the real joint law of the functions and endpoint has density W relative to the ideal one. If S were retained, the density would instead be N times the indicator that its chain ends at Y; summing out S gives W. The transcript and success event below do not inspect S or private honest evaluations of it. Thus a transcript-measurable success event E has real probability E_ideal[1_E W].

For a partial table of H_j, let K_j be the N by N matrix with a one in the known input's output column for each queried row and zeros in each unqueried row. Let u_j indicate the unqueried rows, and let

    P_j = K_j + u_j 1^T/N.

Conditional on an adaptive ideal transcript, the unqueried cells remain independent uniforms. Since a full chain reads only one cell in each independent function, its conditional expected preimage count is

    w = E_ideal[W | transcript] = 1^T P_0 ... P_(h-1) e_Y.

Let C_r be the number of fully queried suffix paths from layer r to Y, with C_h=1 for the empty suffix. Expanding the matrix product according to its last unqueried transition gives the exact identity

    w = C_0 + sum_(j=0)^(h-1) alpha_j C_(j+1),
    alpha_j = (1^T P_0 ... P_(j-1) u_j)/N.

Every P_j is row stochastic, so its left product has total mass N. Consequently 0 <= alpha_j <= 1, and

    w <= 1 + sum_(r=0)^(h-1) C_r.

This bound is the reason earlier queried functions can be included. Their influence is counted by known suffix paths, rather than assumed independent of the challenge.

Stop at the first complete two-edge suffix or the budget. Before stopping, C_r=0 for every r <= h-2. Only a query to one of the last two functions can cause this stopping event. As in the two-hop proof, its real probability is the sum of the ideal first-success transition probabilities weighted by the resulting conditional likelihood w.

## Queries to the last function

Write k=C_(h-1), the number of already queried last-function inputs whose output is Y. A fresh query at input z can succeed only if there is at least one known H_(h-2) predecessor of z. For each r <= h-2, let m_r(z) count fully known paths from layer r to z, stopping immediately before the last function.

If m_(h-2)(z)>0, the fresh last-function answer equals Y with ideal probability 1/N. On that answer, the suffix counts become C_r=m_r(z) for r <= h-2 and C_(h-1)=k+1. Hence its weighted risk is at most

    (2 + k + sum_(r=0)^(h-2) m_r(z))/N.

Call this last-function query productive. For a fixed r, each distinct queried input at layer r contributes to m_r(z) for at most one productive last-function query: its forward queried path has one endpoint, and that endpoint has only one first query to the last function. Let q_j be the final fresh-query count for function j, and let p count productive last-function queries. Pathwise,

    sum_productive sum_r m_r(z) <= sum_(r=0)^(h-2) q_r,
    p <= min(q_(h-2),q_(h-1)).

The baseline numerators therefore sum to at most

    sum_(r=0)^(h-2) q_r + 2 min(q_(h-2),q_(h-1)) <= 3q/2.

This includes merged candidate paths and any earlier queried prefixes. Neither disjoint attempts nor an internally visible correct-guess flag is assumed.

## Queries to the penultimate function

A fresh penultimate-function query at input a succeeds exactly when its output is one of the k known last-function preimages of Y. Its ideal probability is k/N. For each r < h-2 let m_r(a) count known paths from layer r to a, ending immediately before the penultimate function. On success,

    w <= k+2+M(a),       M(a)=sum_(r=0)^(h-3) m_r(a).

Its weighted risk is therefore at most

    k(k+2)/N + k M(a)/N.

Each earlier queried input can contribute to M(a) for at most one fresh penultimate-function input a. Thus, pathwise,

    sum_penultimate M(a) <= sum_(r=0)^(h-3) q_r <= q.

The count k never decreases, so the total extra numerator is at most q k_final. In the ideal experiment each fresh last-function answer independently equals Y with probability 1/N. Thus E_ideal[k_final] <= q/N, and these extra terms contribute at most q^2/N^2.

## Remaining arithmetic

The last-function queries have a remaining k/N term, and the penultimate queries have k(k+2)/N. After t total queries, k is dominated by Binomial(t,1/N), even under adaptive allocation among the functions and stopping. Since k <= k(k+2), a common bound at every step is

    E[k(k+2)]/N <= 3t/N^2 + t(t-1)/N^3.

Summing for t=0,...,q-1 and adding the baseline and prefix terms proves the claim.

## Remaining application gap

The proof now handles a single target whose preceding chain values are derived by accessible random functions. It does not permit multiplying this result across adaptive challenge choices while preserving its coefficient. Applying a q-budget version separately to each of 42 chains would lose a factor of 42. A joint argument needs to charge the actual allocation in one experiment, also covering forgeries requiring one backward step in each of two different chains. Transferring it to SPHINCS further requires queries before signatures and the fixed-message encoding preparation event. Those remain paper proof obligations.
