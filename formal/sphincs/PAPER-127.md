# Continuing from 126 to 127 bits

The 126-bit theorem is proved. The 127-bit bound is proved for every original hash budget $q\ge3\cdot2^{114}$ by [security127_of_large_budget](SphincsSecurity/Proof/Security127LargeBudget.lean). The full 127-bit theorem remains unfinished because smaller positive budgets still need their bound. Keep the original scheme, SUF game, signing cap and whole-experiment hash budget in [Statement.lean](SphincsSecurity/Statement.lean) fixed.

The completed large-budget reduction uses `forgeAdvantage_le_native_bound`: for $x=q/2^{128}$ and $q\le2^{127}$, original SUF probability is at most $2x-x^2+(11/65536)x+q/2^{169}+2^{-700}$. Exact Lean arithmetic bounds this by $q/2^{127}$ when $q\ge3\cdot2^{114}$; larger budgets use probability at most one. The reference dummy is explicitly instantiated by a proved valid encoding, so `security127_of_large_budget` has only the original hash-bound premise and the budget-range condition.

The native bookkeeping invariants, whole-run exception classification and both exception histories are bounded. `exceptionHistorySourceGame_prefix_le` gives $2^{-700}$. `exceptionHistorySourceGame_cache_le` gives $q/2^{169}$ by freezing a second-moment weight at the first exception, accumulating native message charges and bounding them by actual hash calls. Both histories include failed signing invocations and steps after the certificate monitor stops. Erasing their passive flags recovers the monitored source game exactly.

The OTS query interpreter is defined in [OtsPrefixSimulation.lean](SphincsSecurity/Proof/OtsPrefixSimulation.lean). For each fixed oracle, it reconstructs the original game after secret sampling, including the signing log, verification and original hash-cost trace. Its program is unchanged when private prefix entries in its auxiliary oracle are replaced arbitrarily. Each external prefix query requests one low reply and combines it with the full reply's high part; the reconstructed signer makes no prefix queries.

The raw sampling decomposition is proved in [OtsPrefixReferenceSeed.lean](SphincsSecurity/Proof/OtsPrefixReferenceSeed.lean). Conditional on the reference family, the low prefix tables are uniform and independent of the auxiliary seed, whose distribution uses no secret-key fields. The prefix depth may be chosen from that reference family. A uniform encoding table over a fixed domain supplies the remaining encoding rows. Rebuilding the oracle from these samples has exactly the original reference-family oracle distribution, and its prefix low and high replies equal the sampled rows.

The endpoint reconstruction is proved in [OtsPrefixSeedReconstruction.lean](SphincsSecurity/Proof/OtsPrefixSeedReconstruction.lean). Auxiliary oracle and frontier reconstruction uses the selected private prefix only through its endpoint. Replacing the chosen starting-secret field leaves the endpoint-supplied program unchanged. [OtsPrefixSourceGame.lean](SphincsSecurity/Proof/OtsPrefixSourceGame.lean) gives an exact original-game representation using this program with that secret field set to zero, independent low tables and auxiliary seeds. The real source inherits the original whole-experiment hash budget.

The chosen starting secret is separated from the other secret coordinates by an exact finite equivalence in [OtsPrefixSecretSampling.lean](SphincsSecurity/Proof/OtsPrefixSecretSampling.lean). [OtsPrefixObservedSource.lean](SphincsSecurity/Proof/OtsPrefixObservedSource.lean) identifies the original source with a mixture of the generic observed-prefix real runs. Discarding the endpoint and observed rows preserves the original forgery probability and hash-cost trace. [OtsPrefixObservedBudget.lean](SphincsSecurity/Proof/OtsPrefixObservedBudget.lean) transfers the original hash budget to each supported conditional real run.

The bounded OTS interface is supplied by [OtsPrefixCappedSource.lean](SphincsSecurity/Proof/OtsPrefixCappedSource.lean). An analytical cap stops before the next prefix query would exceed $q$, returning an ordinary result rather than dropping probability mass. Its syntactic query bound is unconditional. The explicit prefix counter is bounded by the original hash-cost trace, so the cap erases exactly on every supported conditional real run. For $q<2^{128}$, the positive likelihood factor puts ideal support inside real support: the ideal cap never stops either, and its completed outputs obey the original whole-experiment hash budget. The concrete capped interface needs no additional prefix-query-bound premise.

The shared OTS-prefix allocation is proved in [ReferenceFamilyAllocation.lean](SphincsSecurity/Proof/ReferenceFamilyAllocation.lean). One recorded external-query program preserves the original SUF probability, and the sum of its counts over all OTS prefixes is at most the original budget, both for each supported execution and in expectation. [OtsPrefixAllocation.lean](SphincsSecurity/Proof/OtsPrefixAllocation.lean) identifies each fixed-oracle interpreter count with its charge in this common program. The analytical cap also preserves the original result jointly with its prefix-query count.

The counter transport through reference sampling and the secret split is proved in [OtsPrefixSeedAllocation.lean](SphincsSecurity/Proof/OtsPrefixSeedAllocation.lean) and [OtsPrefixObservedAllocation.lean](SphincsSecurity/Proof/OtsPrefixObservedAllocation.lean), preserving the result jointly with its actual prefix-query count. [OtsPrefixIdealAllocation.lean](SphincsSecurity/Proof/OtsPrefixIdealAllocation.lean) averages the capped likelihood comparison over those samples and proves $(1-q/2^{128})\sum_c\mathbb E Q_c^{\rm ideal}\le q$. For $q<2^{128}$, the established cap contract excludes termination in the ideal law. The loss is one uniform likelihood factor, with no factor for the number of chains.

The joint reservation is proved in [ReferenceQueryAllocation.lean](SphincsSecurity/Proof/ReferenceQueryAllocation.lean). The recorded original law satisfies $Q+A_{\rm enc}+A_{\rm other}+A_{\rm msg}\le q$ on every supported execution. The conditional comparison preserves that reservation: $(1-q/2^{128})\sum_c\mathbb E Q_c^{\rm ideal}+\mathbb E_R[A_{\rm enc}+A_{\rm other}+A_{\rm msg}]\le q$. The message charge counts every proper message call at the actual public parameter, including internal signing attempts, repetitions and verification. External encoding and other non-message charges conservatively count all calls, so they also bound the fresh nonreference and structural subsets used by the paper estimates. External message calls are included only in the native message trace.

The generic first-contact bound is proved in [AdaptiveChainContact.lean](SphincsSecurity/Proof/AdaptiveChainContact.lean): $\Pr_R[\mathrm{contact}]\le2\mathbb E_I Q/2^{128}$ for arbitrary adaptive prefix programs starting with no observed rows. Here contact means a queried last-level row returns the published endpoint, and $Q$ counts actual selected-prefix queries. A pending-path potential accounts for earlier preparation, including one query completing several paths. [AdaptiveChainCapObservation.lean](SphincsSecurity/Proof/AdaptiveChainCapObservation.lean) preserves the endpoint, original result and observed rows through cap erasure. [OtsPrefixContactProbability.lean](SphincsSecurity/Proof/OtsPrefixContactProbability.lean) averages the bound over the concrete conditional source and sums it using the joint budget, retaining the original encoding, other-hash and message reservation.

[AdaptiveChainRestart.lean](SphincsSecurity/Proof/AdaptiveChainRestart.lean) proves the fixed-endpoint restart charge for a partial table with no contact: old distinct prefix rows plus twice future queries bound the weighted contact probability. [AdaptiveChainCheckpointContact.lean](SphincsSecurity/Proof/AdaptiveChainCheckpointContact.lean) transports that charge to the joint real law of the checkpoint and continuation. [OtsContactCheckpoint.lean](SphincsSecurity/Proof/OtsContactCheckpoint.lean) instantiates the observation invariant at the first contact on the common external hash trace: trace membership is equivalent to contact in the selected partial table, and its distinct queried rows are bounded by the selected trace count. [OtsContactSplit.lean](SphincsSecurity/Proof/OtsContactSplit.lean) preserves the full external trace when pausing and resuming; two contacted chains imply a marked checkpoint and a new contact afterward. The sum of restart charges over uncontacted chains fits twice the original hash-cost trace. [OtsContactSourceAllocation.lean](SphincsSecurity/Proof/OtsContactSourceAllocation.lean) now transports the frontier and both traces through the conditional source mixtures and proves that the expected sum of marked restart charges is at most $2q$ times the common first-contact probability. [OtsContactCheckpointLaw.lean](SphincsSecurity/Proof/OtsContactCheckpointLaw.lean) projects the joint real checkpoint and continuation to this same distribution. [OtsTraceCheckpointObservation.lean](SphincsSecurity/Proof/OtsTraceCheckpointObservation.lean) supplies the final contact and future-count comparisons. [OtsContactProbability.lean](SphincsSecurity/Proof/OtsContactProbability.lean) applies the restart inequality and averages it back to the common original law.

The distinct-chain estimate is proved in [OtsDistinctContactBound.lean](SphincsSecurity/Proof/OtsDistinctContactBound.lean). With $N=2^{128}$ and $E_2$ denoting two contacted chains on the common external trace, it gives $(1-x)^2N\Pr_R[E_2]\le4x\mathbb E_R Q_{\rm prefix}$ for $q<N$. [OtsContactFirstProbability.lean](SphincsSecurity/Proof/OtsContactFirstProbability.lean) identifies trace contact with the previously bounded observed-table event. The proof sums restart charges once, then applies this first-contact estimate and the common prefix allocation. Its joint version gives $(1-x)^2N\Pr_R[E_2]+4x\mathbb E_R[A_{\rm enc}+A_{\rm other}+A_{\rm msg}]\le4xq$. Both estimates use only the original hash-bound premise and $q<N$, with no factor for the number of chains.

The two-edge estimate is proved in [AdaptiveChainTwoEdge.lean](SphincsSecurity/Proof/AdaptiveChainTwoEdge.lean): both completion orders include the endpoint likelihood and earlier-path preparation, with bound $(3/2+4x+2x^2)\mathbb E_I Q/N$. [OtsPrefixTwoEdgeProbability.lean](SphincsSecurity/Proof/OtsPrefixTwoEdgeProbability.lean) connects the uncapped concrete event to the capped ideal cost and sums over chains while retaining the joint query reservation.

The encoding-marker combinatorics are proved in [EncodingNeighbors.lean](SphincsSecurity/Proof/EncodingNeighbors.lean): a unit transfer lowers one coordinate and raises one other, with at most 41 candidate words per lowered chain and 1722 overall. [EncodingBackwardWitness.lean](SphincsSecurity/Proof/EncodingBackwardWitness.lean) classifies two valid words into equality, a unit neighbor, a decrease of at least two on one chain, or decreases on two distinct chains. [EncodingFreshRow.lean](SphincsSecurity/Proof/EncodingFreshRow.lean) uses the injective concrete decoder to bound neighbor probabilities by $41/N$ and $1722/N$ for an unrestricted row or a row restricted to invalid outputs or the reference word. It proves that the first-success sampler's allowed sets have this property. [OtsEncodingMarker.lean](SphincsSecurity/Proof/OtsEncodingMarker.lean) places these events on the common external trace, proves one query can mark at most one chain, and separates marker queries from prefix contacts. Their adaptive accumulation and both chronological estimates are proved below; connecting them to the accepting-forgery classification remains required.

The encoding program erasure is proved in [ReferenceEncodingErasure.lean](SphincsSecurity/Proof/ReferenceEncodingErasure.lean): for fixed key samples, fixing the reference selections and all non-encoding rows fixes the entire causal adversary program, including signing failures, selected counters, the public root and exact signing costs. A representative encoding table is chosen solely from those fixed data. [ReferenceEncodingSource.lean](SphincsSecurity/Proof/ReferenceEncodingSource.lean) transports this program back to the original instrumented law for an arbitrary trace observer and separates the conditional encoding family from the fixed program. [UniformTableObservation.lean](SphincsSecurity/Proof/UniformTableObservation.lean) proves the exact adaptive posterior identity for finite tables with restricted row supports. [EncodingConditionalObservation.lean](SphincsSecurity/Proof/EncodingConditionalObservation.lean) specializes it to first-success encoding sampling, including exhaustion, and proves every initial row support has the previously established fresh-row property. The contact-before-marker estimate is proved below.

The full encoding observation source is proved in [ReferenceEncodingLazySource.lean](SphincsSecurity/Proof/ReferenceEncodingLazySource.lean). [EncodingTablePrior.lean](SphincsSecurity/Proof/EncodingTablePrior.lean) joins the conditional reference family and all remaining encoding rows into one table with independent allowed row supports. [EncodingOracleObservation.lean](SphincsSecurity/Proof/EncodingOracleObservation.lean) routes each original byte query to that table or the fixed non-encoding environment. Its lazy sampler reveals only the queried rows; erasing its state gives exactly the original instrumented law for any observer. [EncodingMarkerKernel.lean](SphincsSecurity/Proof/EncodingMarkerKernel.lean) gives the $41/N$ and $1722/N$ transition bounds for the combined prior. Markers now require a properly serialized encoding input, which is the domain of this table; `entryMarker_encoding_iff` proves that actual encoding calls retain exactly their candidate-word marker condition. The kernels are accumulated over the adaptive history in the marker-count bound below; the marker-first restart bound is also proved below.

The original-game marker count is proved in [EncodingMarkerAllocation.lean](SphincsSecurity/Proof/EncodingMarkerAllocation.lean): $\mathbb E_R[\#\mathrm{marked}]\le1722\mathbb E_R A_{\rm enc}/N$. [EncodingTraceCache.lean](SphincsSecurity/Proof/EncodingTraceCache.lean) proves that queried rows are fixed to their recorded answers and untouched rows retain the initial conditioned support. [EncodingAdaptiveMarker.lean](SphincsSecurity/Proof/EncodingAdaptiveMarker.lean) bounds newly marked chains at the next adaptive query, including cached replies, by $41/N$ per chain and $1722/N$ overall. [EncodingMarkerAccumulation.lean](SphincsSecurity/Proof/EncodingMarkerAccumulation.lean) accumulates the expected marker-set increments without losing probability mass. [EncodingMarkerBound.lean](SphincsSecurity/Proof/EncodingMarkerBound.lean) returns the bound to the common original contact law, and the allocation theorem identifies its encoding count with the existing recorded $A_{\rm enc}$ jointly with the parameter, reference family and original result. No new adversary premise or separate query budget is introduced.

The marker-first estimate is proved in [OtsMarkerContactBound.lean](SphincsSecurity/Proof/OtsMarkerContactBound.lean). For each chain, pause the original retained transcript when its first encoding marker has been observed. The sum over chains of the probabilities that this checkpoint is marked, the chain has no earlier contact, and a contact appears afterward is at most $3444x\mathbb E_R A_{\rm enc}/[(1-x)N]$ for $q<N$. [OtsTraceRestart.lean](SphincsSecurity/Proof/OtsTraceRestart.lean) generalizes the existing restart proof to any retained-transcript stop; the first-contact proof is a specialization of this same argument. [OtsTraceProbability.lean](SphincsSecurity/Proof/OtsTraceProbability.lean) averages the restart comparison under only the original hash-bound premise. [OtsMarkerContactSource.lean](SphincsSecurity/Proof/OtsMarkerContactSource.lean) couples each marker checkpoint back to the common full transcript, so summing its stopping probabilities uses the proved expected marker count and its shared encoding charge. Earlier prefix preparation remains included in the restart argument.

The contact-before-marker estimate is proved in [OtsContactMarkerBound.lean](SphincsSecurity/Proof/OtsContactMarkerBound.lean): the original full trace contains a chain contact before that chain's first marker with probability at most $82x\mathbb E_R Q_{\rm prefix}/[(1-x)N]$ for $q<N$. [OtsContactMarkerTrace.lean](SphincsSecurity/Proof/OtsContactMarkerTrace.lean) defines this chronological event and counts its fresh marker increments. At each encoding query, the conditional chance of a new marker on an already contacted chain is at most $41\cdot\#\mathrm{contacted}/N$. [QueryTracePotential.lean](SphincsSecurity/Proof/QueryTracePotential.lean) now accumulates history-dependent charges, and [EncodingContactMarkerAccumulation.lean](SphincsSecurity/Proof/EncodingContactMarkerAccumulation.lean) applies it to the exact lazy encoding source. Repeated rows cannot introduce new markers. [EncodingContactMarkerSource.lean](SphincsSecurity/Proof/EncodingContactMarkerSource.lean) preserves the frontier together with the complete trace when returning the bound to the original law. The accumulated charge is at most $q$ times the final contact count. [OtsContactFirstProbability.lean](SphincsSecurity/Proof/OtsContactFirstProbability.lean) bounds that expected count by $2\mathbb E_R Q_{\rm prefix}/[(1-x)N]$, with the earlier first-contact probability result as a consequence. No encoding row is fixed prematurely and no independent per-chain budget is introduced.

The two chronological estimates are joined in [OtsMarkerContactProbability.lean](SphincsSecurity/Proof/OtsMarkerContactProbability.lean). On the original full trace, the probability that some chain is both marked and contacted is at most $[82x\mathbb E_R Q_{\rm prefix}+3444x\mathbb E_R A_{\rm enc}]/[(1-x)N]$. [OtsMarkerContactPartition.lean](SphincsSecurity/Proof/OtsMarkerContactPartition.lean) proves that, absent a contact-before-first-marker anywhere in the trace, a marked and contacted chain has no contact at its first-marker checkpoint and is therefore covered by the marker-first bound. A marker query cannot itself be a prefix contact. The checkpoint transport retains the frontier together with the parameter, reference family, original result and full trace, preserving the contact event exactly. The contact-first event is charged once before the sum over marker-first checkpoints, so the union bound retains both original shared costs.

The two-edge estimate is connected to the original full trace in [OtsTwoEdgeProbability.lean](SphincsSecurity/Proof/OtsTwoEdgeProbability.lean): $\Pr_R[\exists c:\mathrm{twoEdge}(c)]\le(3/2+4x+2x^2)\mathbb E_R Q_{\rm prefix}/[(1-x)N]$. [OtsTraceRows.lean](SphincsSecurity/Proof/OtsTraceRows.lean) proves that every selected-prefix table row corresponds exactly to a matching original serialized query and low reply in the full trace, including repeats. [OtsTraceRowSource.lean](SphincsSecurity/Proof/OtsTraceRowSource.lean) returns this relation to the original observed source without a query-bound premise. [OtsTwoEdgeTrace.lean](SphincsSecurity/Proof/OtsTwoEdgeTrace.lean) defines a two-edge witness as two queried consecutive final-prefix rows, and proves its equivalence to the partial-table event for every prefix depth. [OtsTwoEdgeSource.lean](SphincsSecurity/Proof/OtsTwoEdgeSource.lean) preserves the selected endpoint while erasing the contact observer. The final common-law estimate sums the existing allocated per-chain bounds, and its joint form reserves the original encoding, other-hash and message costs. Extracting these witnesses from an accepting verification remains required.

The next work is the original-game completed-witness classification, connecting accepting strong forgeries to the paid two-edge, distinct-contact, marker/contact, equal-encoding, structural and FTS events. [AdaptiveChainActualBudget.lean](SphincsSecurity/Proof/AdaptiveChainActualBudget.lean) derives the uncapped lazy continuation budget from the real whole-run cost bound and $q<N$, as used by the concrete restart proof without an extra syntactic adversary bound. The forced-FTS transitions also need their coverage estimates. The full 127-bit theorem must combine the resulting small-budget bound with the completed large-budget theorem and pass the axiom audit.
