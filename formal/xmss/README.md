# XMSS security formalization

This Lean project formalizes the classical random-oracle security game from `doc/xmss/main.tex`. It pins Lean and VCVio so that the game, its query accounting, and its probability semantics are reproducible.

The adversary has access to the shared random oracle and a signing oracle. Signing responses are logged. A repeated signing epoch makes the transcript invalid, and the strong-forgery check rejects only an exact replay of the signature returned for the claimed message and epoch. The random-oracle query bound is imposed after the adversary and signing oracle have been simulated, so it covers key generation, adversarial queries, signing, and final verification.

`XmssSecurity.Encoding` implements the concrete little-endian digest parser and proves its injectivity, target-sum incomparability, and the exact 99-edge verification cost. `XmssSecurity.Tweak` implements the 128-bit tweak layout, gives typed addresses to every chain, leaf, Merkle, and message-encoding hash call, and proves that their serialized tweaks are injective. `XmssSecurity.Serialization` and `XmssSecurity.ConcreteHash` serialize concrete values into bytes, construct the exact `tweak || P || payload` random-oracle inputs, prove the required injectivity and domain-separation properties, and define the four concrete hash-call combinators. `XmssSecurity.CacheView` interprets those calls deterministically in a final lazy-oracle cache, including the epoch-dependent left-right ordering of authentication nodes, and proves injectivity of every concrete input family. `XmssSecurity.Wots`, `XmssSecurity.Merkle`, and `XmssSecurity.ForgeryCases` give checked deterministic classifications of both same-epoch strong forgeries and fresh-epoch forgeries into 175 explicitly indexed bad-event slots. `XmssSecurity.ConcreteForgery` instantiates both classifiers with the concrete cache view and derives the structural strong-forgery alternatives from concrete messages and signatures. `XmssSecurity.ConcreteVerify` transcribes verification over any monad providing the hash oracle, `XmssSecurity.ConcreteKeygen` constructs the complete WOTS and Merkle public key, and `XmssSecurity.ConcreteSign` constructs both one encoding attempt and the capped retrying signer. `XmssSecurity.BoundedSign`, `XmssSecurity.BoundedSignQueryBound`, `XmssSecurity.CappedConcreteExecution`, and `XmssSecurity.CappedSigningLogReplay` establish successful-attempt provenance, correctness, encoding-query accounting, final-cache consistency, and the 175-event reduction for the capped signer. The remaining modules prove the complete one-attempt 120-bit theorem, whose event bounds and chain-origin reduction are being generalized to capped retries.

`XmssSecurity.ChainEventDecomposition` proves that each of the 42 chain events is either an exact honest key-generation chain-value guess or an already bounded fresh collision, and traces every positive guessed value to its preceding key-generation query. `XmssSecurity.ChainOriginProbability` retains the private key-generation cache, proves that projecting it away recovers the detailed game, and lifts the chain reduction through that experiment. `XmssSecurity.ChainInputTrace` records attacker-visible hash and signing actions without exposing signer-internal hash calls, proves exact projection back to the source game, and charges every supported trace to the global hash-query budget while reserving one query for final verification. `XmssSecurity.ChainTrajectoryUniformity` exposes every value of one WOTS trajectory, proves exact replay against the cache, proves that each next typed chain address is fresh, and derives that an isolated full trajectory is jointly uniform. `XmssSecurity.ChainTrajectoryComposition` proves that one epoch's trajectory cannot populate another epoch's typed addresses, composes the cache-conditional result over every pairwise-distinct finite epoch list, and derives exact joint probability for the full opaque epoch enumeration without constructing its `2^32` list cells. `XmssSecurity.ChainTableUniformity` packages those trajectories as the concrete epoch-and-digit indexed chain-value table and proves that its marginal distribution is exactly uniform. `XmssSecurity.RandomOraclePresampling` proves that any finite list of absent random-oracle entries can be sampled before an arbitrary computation while preserving its distribution, and records the sampled values with their final cache bindings. `XmssSecurity.MixedOraclePresampling` lifts one-entry, finite-list, and traced presampling through the actual sum oracle that interleaves public sampling with hash queries. `XmssSecurity.RandomOracle` additionally proves the joint programming identity that an ordinary uniform 256-bit answer tape is exactly a uniform 128-bit low-digest tape plus independent uniform high halves. `XmssSecurity.ChainTablePresampling` specializes these results to every edge of a candidate fixed-chain table, splits a uniform table bijectively into independent seed and positive-edge coordinates, identifies a uniform finite edge table with an independent digest tape, constructs a programmed cache that realizes every candidate edge with probability one, proves that matching material forces the concrete WOTS walk to equal the table, shows that the full programmed cache is a deterministic installation of an ordinary uniform 256-bit output tape, exposes the selected chain's seed tape by measure-preserving updates to a uniform full secret, combines both tapes into one ideal fixed-chain material experiment with checked cache replay, and carries conditional candidate-table presampling through real key generation and the complete detailed security game. `XmssSecurity.RevealedHiddenValue` proves that adaptive equality probes against a uniform table retain their `q / 2^128` bound after any fixed set of coordinates is revealed. `XmssSecurity.AdaptiveRevealedHiddenValue` extends this bound to arbitrary randomized disclosure transcripts generated before the remaining hidden table, probe strategies selected by those transcripts, and any real view coupled to this ideal experiment. `XmssSecurity.AdaptiveRevealMonitor` proves the stopped-game form directly for arbitrary randomized controllers: probes consume fuel, disclosures lazily sample coordinates, unresolved guesses are sampled at termination, and the invariant gives exactly `q / 2^128`. `XmssSecurity.RevealProbeOracleSimulation` gives that monitor a finite oracle-program interface with named public-sampling, hidden-probe, and disclosure queries, proves zero probe cost for arbitrary forwarded public randomness, defines eager uniform-table and traced semantics, proves the eager full-table invariant through adaptive disclosures by measure-preserving coordinate updates, and proves that every eager program with at most `q` probes has hit probability at most `q / 2^128`. `XmssSecurity.ChainHiddenTable` normalizes secret seeds and positive chain origins into the same table, parses direct chain-input probes, includes the final forgery as the reserved probe, proves that every winning origin event hits this table with at most `q` probes, proves that the forged coordinate differs from every signer-revealed coordinate at that epoch, and connects every returned chain value to the table fixed during key generation. `XmssSecurity.ChainRevealFiltering` removes probes to signer-disclosed coordinates, proves that the final forgery probe survives this filtering, preserves the global query bound, proves that installing all recorded disclosures leaves the real key-generation table unchanged, and packages every winning chain-origin event as a successful hidden-table read strategy that avoids all disclosures. `XmssSecurity.ChainTracedGame` retains the action trace through the cached full game, proves exact projection to the ordinary logged experiment, recovers the trace and key-generation support invariants for every execution, converts every winning chain-origin event into at most `q` successful disclosure-avoiding table probes, and reduces the last probability bound to representing this traced interaction as an eager reveal-probe program. `XmssSecurity.SecretTableUniformity` proves that the complete epoch table of secret WOTS seeds for any fixed chain is jointly uniform and derives its adaptive `q / 2^128` equality-probe bound. `XmssSecurity.SecurityBudget` also proves the weighted 218-unit budget that allows each chain event one hidden-value term plus one collision term while remaining below `q / 2^120`.

The concrete target signer makes at most `2^23` independently randomized encoding attempts and returns `none` only if every attempt fails. Its finite loop is represented directly in `OracleComp`. The completed one-attempt theorem remains available as `xmss_oneAttempt_has_120_bits_of_classical_security`; the canonical `xmss_has_120_bits_of_classical_security` is the capped-signer theorem currently being proved.
